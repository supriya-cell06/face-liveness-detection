# 🔐 LivenessPro — Face Liveness Detection

A web application designed to explore face liveness detection and authentication using web technologies and computer vision.

## ✨ Features

- User login and registration interface
- Face enrolment page
- Face detection using model files
- Multilingual interface
- Camera-based liveness verification (according to the implemented detection logic)

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Face detection models

## 📁 Project Structure

- `index.html` — Login and registration interface
- `enroll_face.html` — Face enrolment page
- `dashboard.html` — Include only if this belongs to LivenessPro
- `style.css` — User interface styling
- `script.js` — Application logic
- `i18n.js` — Language support
- Model files — Face detection resources

## 🚀 How to Run

1. Clone or download the repository.
2. Open the project folder.
3. Follow the required setup instructions for the model files and dependencies.
4. Run it using a local web server if required.
5. Allow camera access to test the supported features.

## 🔒 Security Note

This project is intended for educational purposes. Face detection alone does not prove liveness. Test the implemented liveness checks against photographs and replay attacks before relying on them for authentication.
